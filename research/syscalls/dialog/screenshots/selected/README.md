# Revised font-dialog examples

## Status: INCOMPLETE — unverified examples

The user reported on 2026-11-23 that the interactive demo still does not work
correctly. These revised captures and selection checks do not establish correct
end-to-end interaction. Retain them as investigation evidence, not accepted
reference behavior. See the [research status](../../README.md).

Generated with original Neo 3.21 ROM drawing routines. Generic body text was
removed from the overlapping header/input area of layouts 5/6. Kind-4 choice
inputs use `@A @B @C`, with B selected by the native key handler. Kind-5 inputs
are left unconfigured rather than treating an ordinary prompt as a choice mask.

Body selection highlighting is explicitly enabled through property 5 for body
panes, with selection index 1 (Beta). These are customized examples; the property
is not asserted to be enabled by every constructor. `selection-checks.json`
records the borrowed Beta text pointer, native selected-row attribute and exact
pixel changes from separately captured pre-selection states for 12/13/15.
This does not decode glyphs or establish acceptance-test expected images.

Every controller record has three identical RAM/flag samples. The capture script,
geometry records, pre-selection captures, log, hashes and image reconstruction
code are retained. No model vision was used.

See [interactive demo](../../demo/README.md) for build/run instructions and the
explanation of the initial circled B/C and overlapping body text.

Only the overview contact sheets are retained as notable illustrative output.
Per-layout captures, geometry dumps, RAM records and logs are regenerated by
the gallery source; they are not accepted behavior references.
